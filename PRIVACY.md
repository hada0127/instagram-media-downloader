# Insta Pick Privacy Policy / 개인정보처리방침

Effective date: 2026-11-03. Publisher: hada0127.

## English

Insta Pick helps you save Instagram photos and videos you own or have permission to download. It is an independent extension, not affiliated with Instagram or Meta.

### Information processed

The extension reads the Instagram post URL/identifier, caption, photo/video URLs, thumbnails, media type, sequence and item count needed for its download controls. Captions can contain names or other personal information written by their authors. It inspects the visible page to place controls and identify the current slide. Visible feed posts may be read automatically to display the item-count badge; opening the popup and clicking “게시물 읽어 오기” reads the current post. Files are downloaded only when you press a save button.

Processing occurs in your browser. Popup results (post URL, caption and media metadata/URLs) are temporarily kept in chrome.storage.session so the popup can reuse them during the browser session. This session cache is cleared when the browser session ends or the extension is disabled, reloaded, updated or removed. Downloaded files and Chrome's download history remain on your computer until you delete them through your operating system or Chrome.

### Network requests and recipients

Requests go directly to Instagram and Instagram/Meta media delivery servers to obtain post information, thumbnails and requested files. Those services receive the network information required for these requests, including your IP address and any login credentials the browser automatically attaches to applicable requests. The extension does not request your password, read/export cookies through a cookies API, or send authentication data to the developer. It uses the Instagram session already available in the page; it does not bypass access controls.

The developer operates no data-collection backend for this extension and receives no browsing history, captions, media files, analytics or advertising identifiers from it. The extension does not sell data, use it for advertising, or use it for creditworthiness/lending decisions. Information is used only to provide the stated photo/video saving features. Insta Pick's use of information adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

### Permissions

- Instagram site access: display controls and read the post/media information needed for saving.
- activeTab and scripting: read the current Instagram post after you click the popup's scan control.
- downloads: start user-requested downloads and display their status.
- storage: temporarily retain the popup's collected media list in browser-session storage.

There is no separate registration or payment system. No unrelated browsing across other websites is monitored. You can stop page processing by disabling/removing the extension or restricting its site access in Chrome. Opening the privacy-policy or support link connects to GitHub, which applies its own privacy policy.

For questions or requests, contact the publisher using the developer contact shown in the Chrome Web Store listing or open an issue at https://github.com/hada0127/instagram-media-downloader/issues. Do not include private post URLs, signed media URLs, credentials or downloaded private media in public issues. Policy changes will be published on this page with an updated effective date.

## 한국어

Insta Pick은 본인 소유이거나 저장 허락을 받은 Instagram 사진·영상을 저장하는 독립 확장 프로그램입니다. Instagram·Meta의 공식 제품이 아닙니다.

저장 버튼 배치와 현재 항목 식별을 위해 화면을 읽으며, 게시물 주소·식별자·본문·미디어 주소·미리보기·종류·순서·개수를 브라우저 안에서 처리합니다. 본문에는 작성자가 쓴 이름 등 개인정보가 포함될 수 있습니다. 피드에서 보이는 게시물은 개수 배지를 위해 자동으로 읽을 수 있습니다. 팝업의 ‘게시물 읽어 오기’를 누르면 현재 게시물을 읽습니다. 파일 저장은 사용자가 저장 버튼을 누를 때만 시작합니다.

팝업에서 읽은 목록은 chrome.storage.session에 임시 보관합니다. 브라우저 세션이 끝나거나 확장을 사용 중지·새로고침·업데이트·제거하면 해당 임시 저장소가 지워집니다. 이미 받은 파일과 Chrome 다운로드 기록은 사용자가 운영체제나 Chrome에서 별도로 삭제할 때까지 남습니다.

게시물·미리보기·파일 요청은 Instagram 및 Meta 미디어 서버에 직접 전송됩니다. 상대 서버는 IP 주소 등 연결 정보와 브라우저가 해당 요청에 자동으로 붙이는 로그인 정보를 받을 수 있습니다. 확장은 비밀번호를 요구하거나 cookies API로 쿠키를 읽어 내보내지 않으며, 개발자에게 인증 정보를 전송하지 않습니다. 기존 로그인 상태를 이용하고 접근 제한을 우회하지 않습니다.

개발자는 이 확장을 위한 수집 서버를 운영하지 않으며 방문 기록·본문·미디어·분석 정보·광고 식별자를 전달받지 않습니다. 데이터 판매, 광고 이용, 신용도·대출 판단에 사용하지 않습니다. 정보는 명시한 사진·영상 저장 기능에만 사용하며 Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

Instagram 사이트 접근은 저장 버튼과 미디어 읽기, activeTab·scripting은 팝업에서 현재 게시물 읽기, downloads는 사용자가 요청한 다운로드와 상태 표시, storage는 세션 임시 목록에 사용합니다. 별도 회원가입·결제 시스템은 없고 다른 사이트의 일반 방문 기록을 추적하지 않습니다. Chrome에서 확장을 끄거나 지우거나 사이트 접근을 제한할 수 있습니다. 개인정보처리방침·지원 링크를 열면 GitHub에 연결되며 GitHub의 정책이 적용됩니다.
