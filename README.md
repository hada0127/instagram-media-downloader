# Insta Pick ↘

인스타그램 게시물의 **사진·영상을 한 개씩, 선택한 항목만, 또는 전체 다운로드**하는 Chrome 확장 프로그램입니다.

> **v0.2.10 미리보기 버전** — 일반 게시물·릴스 화면에 아이콘을 표시합니다. 자동 테스트 및 실제 릴스 1건의 MP4 영상·음성 파일을 확인했습니다. Instagram의 화면이나 비공식 데이터 형식이 바뀌면 수집이 실패할 수 있습니다.

## 설치

1. [Releases](https://github.com/hada0127/instagram-media-downloader/releases)에서 `insta-pick-0.2.10.zip`을 내려받아 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 도구 모음의 확장 프로그램 메뉴에서 **Insta Pick**을 고정합니다.

소스를 복제했다면 저장소 루트가 아닌 **`extension/` 폴더**를 선택합니다. Chrome 웹 스토어 배포본은 아닙니다.

## 사용

**확장 팝업이나 호버 없이, Instagram의 기본 버튼 옆에 다운로드 아이콘이 항상 표시됩니다.** 업데이트 직후 이미 열려 있는 Instagram 탭은 한 번 새로고침합니다.

- 일반 게시물의 **즐겨찾기 왼쪽**에는 개별 저장과 전체 저장 아이콘 두 개가 표시됩니다. 두 아이콘의 모양은 같고, 전체 저장에는 오른쪽 위에 전체 항목 수 배지가 표시됩니다. 개수를 확인하지 못하면 `…`로 표시합니다. 피드에서도 영상 한 개로 확인되면 전체 저장 버튼을 숨깁니다. 릴스 전용 화면과 피드 영상을 눌러 연 확대 화면의 **좋아요 위**에는 영상 저장 아이콘 하나만 표시됩니다. 아이콘 위에 마우스를 올리면 기능 설명을 확인할 수 있습니다.
- **현재 항목 저장**: 현재 화면에 보이는 사진 또는 영상 하나를 저장합니다. 여러 장 게시물에서 다음 장으로 넘기면 그 항목을 저장합니다.
- **게시물 전체 저장**: 해당 게시물의 사진·영상을 모두 개별 파일로 저장합니다.
- 홈 피드의 게시물과 게시물 상세 화면에서 동작하며, 새로 로드된 게시물에도 버튼을 붙입니다. Instagram의 화면 구조 변경에 따라 표시되지 않을 수 있습니다.
- 현재 항목을 확실하게 식별하지 못하면 첫 사진을 임의로 저장하지 않고 안내합니다. 전체 목록이 불완전하면 전체 저장을 시작하지 않습니다.

기본 다운로드 폴더에 하위 폴더 없이 바로 저장합니다. 파일명은 **본문 앞 10자_01.jpg** 또는 **본문 앞 10자_01.mp4** 형식이며, 게시물 순서대로 `01`, `02`를 붙입니다. 이모지·특수문자를 모두 제거하고 글자·숫자·공백만 남긴 뒤 앞 10자를 사용합니다. 줄바꿈은 공백으로 정리합니다. 파일명 구분용 밑줄과 확장자 점은 유지합니다. 본문을 읽을 수 없거나 비어 있으면 게시물 번호를 사용합니다. 시작 안내는 완료를 뜻하지 않으며, `chrome://downloads`에서 완료/실패를 확인합니다.

기존 확장 팝업도 사용할 수 있습니다. 게시물이나 릴스 상세 주소에서 **게시물 읽어 오기** 후 체크박스로 선택 저장합니다. 부분 수집 목록은 같은 탭에서 다시 읽으면 누적되고 브라우저 세션 종료 시 사라집니다.

## 지원 범위와 한계

- 단일 사진, 여러 장 게시물, 사진·영상 혼합 게시물, 직접 MP4 주소를 확인할 수 있는 릴스/영상
- 제공받은 후보 중 가장 큰 해상도를 선택합니다. 원본 업로드 품질을 보장하지 않습니다.
- 여러 계정/프로필 전체 자동 수집, 스토리, 라이브, 스트리밍 조각 결합은 지원하지 않습니다.
- 접근 권한 우회 기능은 없습니다. 현재 로그인으로 열 수 있는 게시물에만 사용합니다.
- `blob:` 영상만 있고 실제 영상 주소가 없으면 저장할 수 없습니다. 영상의 표지 사진을 영상으로 대신 저장하지 않습니다.
- 로그인 만료·요청 제한·CDN 주소 만료 시 게시물을 새로고침하고 다시 읽습니다. 강제 재시도나 인증 우회를 하지 않습니다.
- 자신이 소유하거나 저장 권한이 있는 콘텐츠에 사용해 주세요.

## 개인정보와 권한

외부 수집 서버, 분석 도구, 계정 비밀번호 입력란이 없습니다. Instagram 페이지에서는 게시물 위치를 감지해 버튼을 표시합니다. 화면에 보이는 게시물의 개수 배지를 위해 미디어 정보를 읽고, 파일 다운로드는 저장 버튼을 누를 때 실행합니다. 데이터 요청은 Instagram, 파일 요청은 Instagram/Meta CDN으로 전송됩니다.

| 권한 | 용도 |
| --- | --- |
| Instagram content script | 인스타그램 페이지에 저장 버튼 자동 표시 |
| `activeTab` | 사용자가 연 현재 탭에 일시적으로 접근 |
| `scripting` | 현재 게시물의 미디어 정보 읽기 |
| `downloads` | 파일 다운로드 및 완료/실패 확인 |
| `storage` | 브라우저 세션 동안 같은 탭의 수집 목록 유지 |

임시 목록에는 게시물 식별자와 미디어 URL이 포함됩니다. 디스크 영구 저장소나 외부 서버로 전송하지 않습니다. 쿠키를 별도로 읽거나 복사하지 않고, Instagram의 같은 출처 요청에 기존 로그인 상태를 사용합니다.

## 개발

Node.js 20 이상, Python 3. 외부 npm 의존성이나 빌드 단계 없이 동작합니다.

```sh
npm test
npm run check
npm run package
```

패키지: `dist/insta-pick-0.2.10.zip`. 상세 구조는 [설계 문서](docs/architecture.md), 검증 범위는 [검증 기록](docs/verification.md)을 참고하세요.

Chrome API 근거: [scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting), [downloads](https://developer.chrome.com/docs/extensions/reference/api/downloads), [storage](https://developer.chrome.com/docs/extensions/reference/api/storage).

- v0.2.10: 전체 저장도 개별 저장과 같은 기본 다운로드 아이콘을 사용하며 우측 위 숫자 배지로 전체 개수를 표시한다. 화면에 보이는 게시물마다 한 번 정보를 읽으며, 확인되지 않은 개수는 `…`로 표시한다. 릴스는 배지 없이 버튼 하나다.
